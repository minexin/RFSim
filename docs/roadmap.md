# RFModel 中长期目标路线

## 目标（12-24个月）
形成可替代部分 SystemVue RF Design 库工作流的国产射频系统级频域仿真平台，覆盖线性网络、噪声、非线性行为、频率转换、模型管理、参数扫描和自动化验证。

## 版本路线

- **v0.1（0-2个月）**：二端口/N端口 S 参数、网络连接、频率扫描、功率/增益/VSWR。
- **v0.2（2-4个月）**：Touchstone 导入、插值/外推、模型校验、噪声参数与级联噪声。
- **v0.3（4-7个月）**：PA AM-AM/AM-PM、压缩、双音 IMD、IP3/IP5；PHD 作为非线性模型适配器。
- **v0.4（7-10个月）**：Mixer 上下变频、LO 谐波、边带、转换噪声。
- **v0.5（10-14个月）**：参数扫描、优化、Monte Carlo、批处理和 Python API。
- **v1.0（14-24个月）**：稳定模型文件格式、器件库、可视化前端、兼容性报告和完整回归体系。

## 工程管理

- `main`：可发布版本；`develop`：集成分支；功能使用 `feature/<topic>`。
- 每个版本必须有 CHANGELOG、能力矩阵、可复现实例和机器可读测试结果。
- 采用小步提交；提交信息使用 `feat`、`fix`、`docs`、`test`、`build` 前缀。
- 每个里程碑结束时打版本标签，并保留参考结果和误差阈值。
