# RFModel 兼容目标与实施路线

> 接口更新（2026-10-13）：Python 产品包、wheel 和 Python/JSON CLI 已退役。本页涉及这些入口的命令与验证属于历史记录；当前 C++ 入口及迁移范围见 [退役记录](python-interface-retirement.md)。保留的物理结论与厂商差异不因退役而改变。

## 最终目标
覆盖 SystemVue 2023 的：

- Linear Analysis
- RF System Analysis
- RF Design 库中的各种器件模块（按 SystemVue 2023 官方目录逐项核验）

目标是形成跨平台的 C++17 射频系统级频域仿真核心。Windows/MSVC 为首要开发环境，同时保持 Linux/macOS 可移植性。GUI 不属于首阶段范围，但核心 API 必须完整、稳定并可被后续 GUI、Python 或其他前端调用。

## 当前主要工作框架（2026-10-16 澄清）

RF Design 的主要角色是行为建模器件库；共享器件与同一系统组网下，Linear 的核心输出是外部 S，
RF System 关注节点/端口谱与路径性能。底层算法为这些行为和测量服务，不因通用算法存在就计作厂商覆盖，
也不因目录检索未命中就断言某能力不存在。这是主要框架，不是完整 SystemVue 2023 规格；
具体支持细节与额外能力仍需按官方版本证据逐项核验，不由此扩展为全 DSP、GUI 或通用 SPICE 目标。

[同一行为模型/接线表的 SDK 示例](../examples/behavioral-system-sdk/README.md)演示现有 C++ 接口组合。
[历史通道测量帮助来源](../validation/systemvue-2023-channel-noise-help-provenance.json)保留既有出处与哈希；
完整 2023 正文在本轮核验中尚未可读，历史帮助摘要与新的运行实验分开解释，示例不宣称厂商测量等价。
后续本地只读资料核验与最小实验见[2023 行为级核验清单](systemvue-2023-behavioral-handoff.md)。
以下历史路线和证据保持原样。

## 兼容策略

兼容对象按行为能力而不是按类名复制：

1. 线性 N 端口网络：S 参数、阻抗、端口连接、级联、功率、增益、VSWR、稳定性。
2. RF System Analysis：频率扫描、链路预算、网络求解、噪声、参数扫描和结果导出。
3. RF Design 器件：滤波器、放大器、衰减器、延迟线、电缆、耦合器、功分/合路器、天线、混频器、终端、振荡器和测量数据模型。
4. 非线性行为：AM-AM、AM-PM、P1dB、IP3/IP5、谐波和双音 IMD；PHD 仅作为具体多谐波模型适配器。

每种器件记录“支持、部分支持、暂不支持”和与 SystemVue 2023 的观测差异，不承诺未经测试的名称级兼容。

## 历史版本路线（非当前工期）

以下月份是早期规划假设，保留用于理解阶段顺序；不能换算当前完成百分比、剩余工期，
也不构成全目标完成或发布日期承诺。Python 产品入口后来已退役，旧路线中的 Python/C API
表述不改变当前 C++17 优先的交付范围。当前实现与证据以[能力索引](compatibility-evidence.md)为准。

- **v0.1（0-3个月）**：跨平台 C++17 API、S 参数模型、二端口/N 端口网络、频率扫描、功率/增益/VSWR。
- **v0.2（3-6个月）**：Touchstone 读取、插值与校验、终端/衰减器/延迟线/滤波器/耦合器/功分器。
- **v0.3（6-9个月）**：噪声参数、噪声系数、噪声温度、级联噪声、LNA/PA 小信号模型。
- **v0.4（9-13个月）**：PA 非线性、双音 IMD、IP3/IP5、P1dB、PHD 模型适配。
- **v0.5（13-17个月）**：Mixer 频率转换、边带、LO 谐波、转换增益和变频噪声。
- **v0.6（17-20个月）**：参数扫描、优化、Monte Carlo、批处理、Python/C API。
- **v1.0（20-24个月）**：RF System Analysis 完整工作流、器件库、模型文件格式、兼容性报告和可选 GUI。

## 当前进展与依赖（2026-10-15）

有界 PLL/共享复相位/有限频带 jitter、installed SDK 工作流、raw reader/catalog 及只读重放工具、
线性 MNA/DC/AC、复参考 MNA→S、Touchstone raw 噪声导出及显式等温 MNA 噪声 SDK 示例
已有原生实现与独立证据。它们不等于完整 PNCP、SPICE、
瞬态或厂商库验收。RFAMP 单 profile 的 A/B/C/D 与 380 独立 holdout 已完成；专有系数律仍缺。
DC/RC 八次分析提交而零项比较验收，实际四文件 X-parameter 重放仍未运行，完整系数/参考面
与各器件族验收仍需独立证据。243 项目录仅为库存，不是覆盖率分母或完成数。

后续顺序由明确缺口、可取得的厂商证据和用户产品选择决定，不能靠新增示例或 CI 数量闭合。
公开分发、许可、版本/标签、API/ABI 稳定性及最终精确提交门禁尚未关闭；本轮不作这些决定。

## 首阶段验收（保留原条件）

- MSVC、Clang 和 GCC 均可构建核心库。
- 解析网络与 SystemVue 2023 结果逐频点对比。
- 支持 Touchstone 1/2 端口模型和显式参考阻抗。
- API 不依赖 Windows、GUI 或具体前端。
- 所有案例包含输入、输出、版本和误差阈值。
