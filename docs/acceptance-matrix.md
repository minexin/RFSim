# 能力边界与验收矩阵

| 能力 | M1 | 后续 |
|---|---:|---:|
| 二端口/N 端口 S 参数 | ✅ | - |
| 任意端口网络连接 | ✅ | - |
| 频率扫描、功率、增益、VSWR | ✅ | - |
| 噪声系数/噪声参数 | - | M2 |
| PA AM-AM/AM-PM、P1dB、IP3 | - | M3 |
| PHD 多谐波模型适配 | - | M3 |
| Mixer 频率转换 | - | M4 |
| 模型文件格式和器件库 | - | M5 |

每项后续能力均需提供参考结果、机器可读输入输出和误差阈值，不能只以示例运行成功作为验收。
