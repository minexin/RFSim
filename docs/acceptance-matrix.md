## 独立复参考阻抗（2026-10-09）

已实现逐频率/端口的功率波 S 与内生噪声重归一化，以及物理 Z/Y 转换；C++、C ABI、Python、线性 JSON 入口齐备。解析负载、多端口电压电流、净功率和热噪声关系用于独立验证。SystemVue 的 ZPORT/CS 语义和复参考数值对照仍未验收，见[接口及证据边界](power-wave-references.md)。

## 原生 PHD 固定泵浦基础（2026-10-14）

显式单幅度 F/S/T 切片、谐波相位冻结、严格 DC gauge、固定正实参考阻抗及
参考面标识、拥有数据的受限扰动 Jacobian 已实现。泵浦扰动会拒绝，且不暴露
可被误用于变泵浦求解的通用转换模型。独立复数、相位协变、非泵浦有限差分及
安装后双 TU 测试见 [系数契约](phd-coefficient-contract.md)。完整泵浦导数、
系数提取/插值、厂商文件和 SystemVue2023 数值兼容性仍未验收；不推断噪声。
