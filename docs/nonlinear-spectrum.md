# 无记忆多项式频域内核

`nonlinear_spectrum.hpp` 提供 `RealVoltageSpectrum` 和 `MemorylessPolynomial`。它是非线性器件的运算基础，不是 PHD 模型，也尚未加入含反射的非线性网络迭代。

频谱采用公共频率间隔 spacing_hz（正有限 Hz）和非负整数频率索引。索引 k 对应 k*spacing_hz；系数是实电压傅里叶级数的正频率项：v(t)=V0+2*Re(sum Vk*exp(j*2*pi*k*spacing_hz*t))。DC 必须为实数。峰值 A、相位 phi 的余弦对应 Vk=A*exp(j*phi)/2，不能直接把 RMS 电压或功率波代入。

`MemorylessPolynomial({a0,a1,...})` 表示 y(t)=sum an*v(t)^n，系数单位为输出伏特/输入伏特的 n 次方，最高九阶。实系数模型可产生幅度非线性、谐波、互调和 DC 偏移；不描述 AM-PM、记忆效应或频变非线性。

实现自动构造负频率共轭项，以 Horner 法和稀疏卷积计算完整输出。相同频率分量相干相加，无频率折返、无隐式截带。频率索引溢出、数值溢出及资源超限均报错。当前限制输入非负频率项 2048 个、中间有符号频率项 4096 个、一次计算最多一千万次乘积；这些是原型资源边界，不是物理带宽限制。

解析回归：两个峰值均为 1 V 的余弦，通过 y=x+0.1*x³，验证基波、三次谐波、2f1-f2/2f2-f1 和和频互调；DC 偏置经平方产生正确的 DC、基波与二次谐波。另用带任意相位的多音信号，在 31 个时刻独立重建波形并与时域多项式结果比较。频率与幅值溢出被拒绝。

仍需完成：非线性器件端口契约、功率归一化、P1dB/IP3 参数映射、AM-AM/AM-PM、频变与记忆模型、闭环谐波平衡、PHD 适配、变频噪声和 SystemVue 2023 数值对照。当前解析回归不代表完成 RF System Analysis 非线性兼容。
