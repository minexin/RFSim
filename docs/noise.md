# 噪声接口与验证范围

`NoiseProvider` 提供频点对应的标量噪声参数。`NoiseParameters` 支持非负有限噪声系数、正有限参考温度和等效温度换算，并拒绝溢出。当前接口约束不覆盖负噪声系数的特殊模型。

`cascade_noise_figure_db` 适用于使用一致噪声参考条件、以相应线性功率增益描述的单向级联。输入增益和噪声系数单位为 dB，内部转换为线性值计算 Friis 公式；它不是含反射、相关噪声或变频的通用网络噪声求解器。

2026-09-22：MSVC Debug/Release 全套 CTest 各 8/8 通过，包含噪声测试。解析基线：F1=2、F2=3、G1=10 得到总 F=2.2；10 dB 常温衰减器前置于 F=2 放大器得到总 F=20；F=2、T0=290 K 对应 Te=290 K。

测试还包含空链、零噪声系数、NaN、负噪声系数、无效温度和极端溢出。此前仅执行测量测试不能证明噪声模块通过；本次首次完成 noise_test 的双配置验证。

已有[二端口 NFmin/Rn/GammaOpt 提取](noise-figure.md)。固定泵有限频率通道的 [FrequencyConversionModel](frequency-conversion.md) 与 [FrequencyConversionNetwork](conversion-network.md) 已支持给定直接/共轭转换矩阵、源与内生噪声的 C/P 联合统计及实 DC 噪声；[loaded-noise 接口](conversion-loaded-noise.md) 可返回入射、出射、交叉统计与逐通道净吸收噪声密度。这些接口求解显式给定模型和边界下的统计量，不代表任意变频器噪声建模或与 SystemVue 测量语义等价。相关矩阵基础接口见下文。

## 相关噪声矩阵基础接口

`noise_matrix.hpp` 定义 `NoiseCorrelation`，其 `watts_per_hz` 存储 Cij=E[ci*conj(cj)]，单位 W/Hz，使用功率归一化波及正实数参考阻抗。它与现有标量 NoiseProvider 并存；还没有把两者相互转换。

`passive_thermal_noise(S,T)` 在经典热平衡近似下计算 kB*T*(I-S*S†)，kB=1.380649e-23 J/K。T 是器件均匀物理温度，可以为零；即使 T=0 也检查无源性。该公式的参考来源：[Caltech 噪声波分析报告](https://www.kiss.caltech.edu/papers/reports/oliver-king-final-report.pdf)。不含量子修正、外部源/负载噪声或器件间温差分布。

`propagate_noise(H,C)` 计算 H*C*H†，目前 H 是与 C 相同阶数的方阵。H 必须由调用方给出；本接口不会从网络连接自动求出 H，网络求解和扫描通过上层接口连接，见 linear-noise-sweep.md。

输入相关矩阵需有限、Hermitian、半正定。首先使用既有全局尺度的对角选主元半正定 Cholesky 准入及投影，归一化门限仍为 256*n*epsilon。门限内的剩余块先视为零；显著负定或非 Hermitian 输入仍被拒绝。无源性检查以 I-S*S† 的元素最大幅度或 1（取较大者）作为尺度，保持原规则；普通相关矩阵以自身最大幅度归一化。上限 1024 端口，算法为稠密矩阵实现。

### 完全独立弱块的保留范围

普通相关矩阵在全局准入后，可以恢复原始输入中完全独立、且所有行都被原因子完全丢弃的块。
两个端口只要任一方向的原始相关项精确非零，就属于同一个连通分量；不使用近似零门限。
只有整个分量在所有原因子列中均精确为零时，才按该分量自身尺度应用同一套局部
Hermitian/PSD 投影。局部失败仍保留原来的全局投影，不改变输入是否被接受。
任何非零 scale floor 都直接使用原投影，因此无源性与损耗舍入容差没有改变。

这是正独立弱块的保留契约迁移：例如 diag(1,1e-16) 的第二项现在保留；
diag(1,-1e-16) 仍被接受并投影成零，局部 Hermitian/PSD 准入失败的弱块也不会被恢复。
原因子列、列序和公共尺度逐 bit 保留，新列仅追加在原来全零的独立行上。
不重新分解全矩阵，也不把强块的 Schur 舍入残差当成新物理噪声。

该恢复有明确的浮点表示范围：每个原始非零实部/虚部除以全局尺度后必须是 normal double；
局部/全局尺度比、其平方根，以及每个局部非零因子实部/虚部缩放到公共尺度后的结果
也必须是 normal。局部填充项可能在原输入满足范围检查时仍下溢，故先暂存整个块，
任何系数变成次正规数、零或非有限值时都整块回退，不追加部分结果。
此范围检查不改变旧列已有的表示范围；绝对很小但归一化后正常的输入仍可处理。
图扫描为 O(n²)，额外分解成本为各完全丢弃独立块的成本之和；每块至多一次非递归局部分解。

这不是任意参考阻抗或任意基底不变性：已部分保留的连通块、同一连通块内的混合尺度弱模式、
强秩一因子的既有舍入误差，以及上述范围外的块保持原结果。普通 Gram 重构仍受双精度
乘积范围限制。局部投影仍按其自身 256*m*epsilon 门限丢弃小残差，不保证保留所有正特征值。

### 因子域传播的数值边界

`propagate_noise` 保留输入检查得到的半正定因子 L（包含主元排列恢复），
先计算 W=H*L，再只计算 Gram 矩阵的一侧并共轭填充另一侧。
避免先重构 C 再计算 H*C*H† 所产生的相消及伪非 Hermitian 拒绝。
传播不再次按输出最大值投影，因此不会仅因另一输出被大增益放大而丢弃已准入的模式。
零输入保持零；全局输入准入与无源性检查没有放宽。完全独立弱块的保留范围如上。

普通尺度使用补偿累加和乘积残差；严重相消或极端尺度转入二进制指数及浮点残差展开，
避免中间溢出/下溢，
也保留大项相消后的较小项；不依赖 `long double` 比 `double` 更宽。
最终结果仍为双精度 W/Hz，无法表示的结果会被有限值检查拒绝，最终下溢仍可能归零。
低秩源只传播已准入的因子列；满秩稠密运算仍为立方复杂度，稳健累加有额外开销。
这不是任意精度算法：输入舍入、Cholesky 条件数、各连通块内既有容差以下的模式以及其他上层
接口的矩阵重构/检查仍限制精度，不保证任意病态变换的相对误差。

新增原生回归使用已知低秩源因子与独立传播结果，覆盖实/复相消、主元排列、零空间、
零秩、极端尺度及次正规数、非法输入、实/复参考阻抗的 V/I 方程、变频 C/P 和 DC，
并提供安装后双翻译单元消费测试。这些检查不构成 SystemVue 数值对照。

独立弱块回归包含旧列/尺度逐 bit 比较、10,000 组整数秩一强源与独立弱源的选择/放大预算、
实/复相关弱块、端口排列、局部失败回退和有限指数范围。相消反例
[69,100] 的强秩一源与 1e-100 独立弱源，在 [100,-69,1] 传播下仍受旧因子约
2.84e-25 的舍入底噪限制；回归禁止额外添加约 1.11e-8 的伪 Schur 噪声，并另行选择弱源验证预算。
这不代表 10,000 组结果都达到 1e-100 的绝对精度。

真实两支路 50 欧姆电阻的 MNA 回归使用每个输出自身的热噪声密度和独立源预算，
覆盖相同/不同温度、实/复外部参考、匹配辅助参考及 1e8/1e-6 辅助参考。
极端辅助参考下此前被丢弃的弱输出现在恢复；残余反馈/坐标变换误差约 2e-9，
测试物理相对误差界限为 3e-9，不能称为机器精度或一般参考不变性。
这些解析/预算回归不改变任何 SystemVue 对照误差门限，也不新增厂商实测证据。

早期相关噪声矩阵回归使用除以 kT 后的无量纲比较，避免 W/Hz 很小而让绝对误差检查失效。覆盖匹配衰减器、50 欧姆串联电阻的负相关项、无损电感、复数秩一噪声相位传播、交换端口及非法矩阵。该历史阶段 MSVC Debug/Release 全套各 20/20 通过，不包含本次独立弱块改动，不能作为本次跨平台验证证据。完整网络 CS 和 SystemVue 对照仍未完成。
## 网络反馈噪声求解

`LinearNetwork::external_noise(external_ports, intrinsic)` 接收按所有器件全局端口编号排列的内部出射噪声矩阵。独立器件可组成块对角矩阵；有已知跨器件相关性时也可填写非对角块。输入阶数必须等于总端口数，不能仅传外部端口的噪声。

使用 b=S*a+c、a=K*b，解 (I-S*K)*H=I，再计算 H*C*H† 并提取指定外部端口。K 由内部连接和终端反射系数构造。一次分解处理所有右端，复用参数转换的选主元和残差检查，计算为稠密 O(N^3)。外端口顺序决定结果行列顺序，原网络保持不变。

外部端口必须未分配，其余端口必须已有连接或无独立激励的终端。外部端口假设匹配且无入射噪声。terminate 的反射系数只描述反馈，不会自动添加终端热噪声；有温度的负载应作为带本征噪声的一端口器件加入。该接口没有自动把 NoiseProvider 或器件物理温度组装为全局 C，现在可由 analyze_linear 的可选噪声回调进行扫描，见 linear-noise-sweep.md。

回归覆盖两个独立电阻级联与等效网络热平衡公式的一致性、失配终端反射噪声、完全相关源的相干相加、外端口反序、维度错误、缺失边界和奇异反馈。SystemVue 对照仍待执行。
