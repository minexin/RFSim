# SystemVue 2023 兼容性矩阵

状态以实现和证据为准，不以版本计划代替验收。已完成部分 SystemVue 单器件与
链路采集，存在通过点和已知差异；下表不表示任一整类能力已全面兼容。

| 能力 | 当前实现 | 主要剩余项 |
|---|---|---|
| Linear Analysis | N 端口网络、等效 S、F/S/ZPORT 与 W/Hz 相关噪声扫描结果 | 复/独立参考阻抗、CS 归一化对照、DC 线性化与完整后处理 |
| RF System Analysis | 线性频率扫描和功率原语 | 路径/预算语义、频谱、压缩、噪声与变频联合分析 |
| 终端、衰减器、延迟线 | 反射边界、理想匹配损耗和延迟 | 器件级噪声、型号参数与官方模块逐项对照 |
| Filter/Cable/Coupler/Splitter | 可接入表格 S 数据 | 专用参数化模型、完整目录与行为对照 |
| LNA/PA 小信号与噪声 | 静态 S 原语、标量噪声/Friis | 专用器件、噪声参数转换与官方数值对照 |
| 非线性/PHD | 多项式卷积、IIP2/IIP3、总 RF 驱动、P1dB/饱和基波、单音限幅、多音直接/二阶/三阶输出 C++/C/Python/JSON | 多端口限幅、重叠谱/来源语义、AM-PM、高阶标定、网络迭代、PHD；饱和参考带警告，仅用于诊断 |
| Mixer | 固定 LO 理想实数混频、上下边带及 DC/相位处理 | LO 驱动、转换矩阵、杂散、泄漏与变频噪声 |
| 参数优化/Monte Carlo | 未实现 | 参数契约与任务执行 |
| GUI | 后置 | 核心接口稳定后推进 |

[线性分析输出细表](linear-analysis-compatibility.md) 保留官方本机帮助来源。跨平台验证已经完成现有测试范围，详见 [构建记录](build-validation.md)。已从本机 RF Design 索引建立 [243 项目录基线](rf-design-catalog.md)，逐项参数和行为验收仍待完成。

基波压缩/饱和的七点参考、原生接口与边界见 [饱和基波模型](saturating-fundamental.md)。
谐波小信号及压缩区差异见 [截点模型](intercept-amplifier.md)，不能以基波吻合替代
完整非线性频谱兼容。

[双音参考](systemvue-two-tone.md) 已覆盖等功率 1.0/1.1 GHz 的三组输入：小信号
互调通过，高功率的未限幅差异保留。[原生分阶接口](multitone-amplifier.md) 已实现
总 RF 功率限幅并通过指定 36 项功率比对；重叠产物传播/合并语义尚待完善，
不能据此宣称完整多音兼容。

本级互调来源现可在 C++/C/Python/JSON 中逐项展开：三组等功率双音共 48 项
功率验证通过，包括 12 个载频处独立三阶项。跨级身份传播、相位及合并测量
规则仍待实现/验证，详见 [来源契约](multitone-amplifier.md)。

本级来源项已可按实际频率经过线性后级并保留路径快照，见 [项传播接口](term-propagation.md)。
现有验证为解析/接口回归；多级非线性反馈、分支合路身份和厂商链路对照尚未完成。
