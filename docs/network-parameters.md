# S 到阻抗/导纳矩阵转换

`network_parameters.hpp` 提供 `s_to_z(S,Z0)`（欧姆）与 `s_to_y(S,Z0)`（西门子），当前 Z0 为所有端口相同的正实数。

计算 `Z=Z0*(I-S)^(-1)*(I+S)` 与 `Y=(I+S)^(-1)*(I-S)/Z0`。采用部分选主元线性方程求解，不逐元素求逆。返回类型暂复用 SMatrix 的稠密复数容器，仅用于形状和索引，输出数值不再是 S 参数。

奇异/阈值内近奇异转换抛出 domain_error；尺寸、参考值及非有限输入会被拒绝。还没有条件数估计或残差门限，极端病态数值需要后续完善。当前资源上限为 1024 端口。

已验证单端口 100 欧姆、耦合双端口解析 Z/Y、非互易网络、需要交换行的消元及开短路奇异输入。MSVC Debug/Release 全套各 16/16 通过。独立/复数参考阻抗与 SystemVue 对照仍待完成。

## 统一参考阻抗转换

`renormalize_s(S, old_reference, new_reference)` 支持所有端口共用的正实数参考阻抗转换。令 `g=(old_reference-new_reference)/(old_reference+new_reference)`，求解 `(I+g*S)*Snew=S+g*I`。实现使用阻抗比计算 g，避免求和溢出，不经过可能奇异的 Z 矩阵，因此支持理想直通及开短路。

将模型转换到网络的参考阻抗后，再把新参考值传给 `LinearNetwork::add`。参考值不合法、超出浮点分辨率的极端阻抗比、奇异或阈值内近奇异转换均被拒绝；消元阈值保留单位矩阵尺度，防止相消后的微小分母被误当作稳定解。

新增回归覆盖 50/75 欧姆负载、开短路、理想直通、非互易复数网络往返转换、物理 Z 矩阵不变性、转换后接入网络以及奇异输入。MSVC Debug/Release 当前全套各 17/17 通过。逐端口不同参考值、复数参考值和 SystemVue 数值对照仍未实现或验证。
