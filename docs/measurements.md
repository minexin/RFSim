# 端口测量接口

`measurements.hpp` 使用同一正实数参考阻抗下的功率波，入射/出射波的模平方为 W。`port_power(a,b)` 返回入射、出射和净吸收功率 `|a|^2-|b|^2`；器件输出端净吸收功率可能为负，这是流出器件的能量，不是错误。

提供 W/dBm 换算、显式输入输出功率比的 dB 增益、反射系数对应的回波损耗和 VSWR。功率增益函数不自动区分可用增益/工作增益/传输增益，调用者必须选择相应功率定义。

零功率转为负无穷 dBm，完全匹配的回波损耗为正无穷，完全反射的 VSWR 为正无穷。VSWR 拒绝模大于 1 的主动反射系数；负功率、非有限输入等按函数约束报错。

回归包含 0 dBm=1 mW、1 W=30 dBm、VSWR/回波损耗边界，以及二端口衰减器的功率收支。SystemVue 对照仍待执行。
