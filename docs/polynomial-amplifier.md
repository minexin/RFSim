# 匹配多项式放大器

`MatchedPolynomialAmplifier` 提供器件元数据、零输入工作点 S 参数及 `NonlinearTransmissionProvider::transmit`。两端口采用同一正实参考电阻，理想匹配、单向传输。此阶段的 transmit 描述匹配输出负载下的正向谱，不求解输出失配、反向入射或非线性反馈网络。

`PowerWaveSpectrum` 的每个正频率复幅度单位为 sqrt(W)，模平方为该音功率；DC 项必须为实数，模平方为 DC 功率。正频率功率波 a 转为电压傅里叶系数 sqrt(R/2)*a，DC 转为 sqrt(R)*a；输出作逆变换。因此可与线性网络功率定义衔接，但不能把两个频谱类型直接混用。

构造函数接受实电压多项式系数。`from_iip3(name,gain_db,iip3_dbm,R=50)` 生成 y=a1*x+a3*x³，a1=10^(gain_db/20)，a3=-2*a1/(3*R*Piip3)，Piip3 单位 W。这来自等幅双音下基波线性外推项 a1*A 与 IM3 项 3*|a3|*A³/4 的交点，输入每音功率为 A²/(2R)。负三阶系数表示压缩。

该三阶模型的单音输入 1 dB 压缩功率为 (1-10^(-1/20))*Piip3。因此 IP3 和 P1dB 在此模型中不是两个可独立指定的参数。超过弱非线性适用区后，多项式会出现反相及非物理功率增长，不具备饱和限幅；不要将其当作完整 PA 饱和模型。

回归覆盖线性/DC 功率归一化、20 dB 小信号增益对应的 19 dB 压缩点、双音 IM3 外推幅度以及 50/75 欧姆参考下相同功率行为。尚无 AM-PM、器件噪声、频率相关系数、闭环谐波平衡和 SystemVue 差异验证。
