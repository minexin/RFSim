# RFModel 第一阶段目标

## 目标
构建可运行的射频系统线性频域仿真内核，统一接入二端口和 N 端口 S 参数器件，完成任意端口网络连接、频率扫描、功率/增益/驻波比计算，并为噪声、非线性和频率转换保留扩展接口。

## 首个里程碑（M1）
- 统一频率网格、端口和复数波数据结构
- `RFDeviceModel` 基类与 S 参数能力接口
- 二端口/N 端口 S 参数模型
- 网络连接描述与线性求解器接口
- 频率扫描结果对象
- 端到端示例：Source → PA 小信号模型 → Filter → Load

## 明确边界
M1 不实现谐波平衡、晶体管级求解、完整 PHD/Poly-Harmonic Distortion 模型、GUI 和电磁场求解。PHD 作为后续非线性模型适配器名称保留。

## 验收
1. 理想衰减器级联结果与解析值一致。
2. 二端口 S 参数转换后的输入/输出功率可复现。
3. 任意 N 端口连接不依赖器件具体类型。
4. 频率单位、参考阻抗和端口顺序显式记录。
5. 每个案例具备输入、结果和误差阈值。
