## 固定电路与两种分析

共享 DUT：`IN — R1(RES, 50 Ω) — MID — R2(RES, 50 Ω) — OUT`，无旁支。
器件端子顺序固定为 R1 输入/输出、R2 输入/输出；保存实际实例名、引脚名及节点名回读。

- **Linear**：外端口 1=IN、2=OUT，ZPORT 均为实数 50 Ω；单频 100 MHz；关闭 Calculate Noise。
  导出 F、ZPORT 和完整复数 S，明确行=响应端口、列=激励端口；不只取 S21。
- **RF System**：源接 IN，单个非调制 CW，100 MHz、0 dBm 可用功率、0°、实数源阻抗 50 Ω；
  OUT 为实数 50 Ω 负载。Normal 路径按 `IN → MID → OUT` 定向；禁止内部节点起始选项。
  明确关闭热噪声、相位噪声及本实验不需要的非线性谱生成，逐项记录实际设置；不可把无法回读当成已关闭。
- RF 的信道积分需要带宽，因此固定 **1 kHz**、中心 100 MHz；Linear 和确定性电路 oracle 不使用带宽。
  帮助将 CW 谱定义为 1 Hz 宽，0.5 Hz 积分会少 3 dB。本次使用 1 kHz 覆盖整条 CW 谱，
  不验证窄于 1 Hz 的积分，不将 RFModel 离散线表示扩展成一般厂商谱形兼容。
- 记录分析温度 26.85 °C 的实际回读，R1/R2 的 Ta 保持空白并回读。噪声关闭不表示真实电阻没有噪声。
  同时记录频率、功率、阻抗的显示单位与导出单位、路径解析结果、谱约简设置及测量开关。

RF 请求导出 CP、DCP、CV、DCV、ZIN/ZOUT、SZIN/SZOUT、DCR 及 Desired 组的 F/V/P/Z。
开启功率、电压和详细 P/V/Z 输出。CNV/CNP/Noise 组在噪声关闭时仅记录存在性及实际内容，
缺省或未生成不当成零噪声数值验收，也不作为本次最小信号实验的失败条件。

## 独立解析值及参考面

采用 RMS 相量，源开路电压 `Vs=2√(50×0.001)` V，
`I=Vs/(50+50+50+50)=0.00223606797749979` A。
每只电阻单独在 50 Ω 参考下为 `S11=S22=1/3`、`S12=S21=2/3`。
串联 DUT 的完整 S 为 `[[+0.5,+0.5],[+0.5,+0.5]]+j0`，两项反射均为**正** 0.5。

| 物理量 | 解析值 | 含义 |
|---|---:|---|
| 源可用功率 | 1 mW = 0 dBm | 源内部参考，非 DUT 实际吸收输入 |
| DUT 输入交付功率 | 0.75 mW | IN 端净进入 DUT 的功率 |
| MID 向后级交付功率 | 0.50 mW | 给 R2 与负载合计交付的功率 |
| 负载交付功率 | 0.25 mW = −6.020599913279624 dBm | OUT 端从 DUT 流向负载 |
| R1、R2 各自耗散 | 0.25 mW | 两电阻合计 0.50 mW |
| IN / MID / OUT 电压 RMS | 0.335410196625 / 0.223606797750 / 0.111803398875 V | 对同一地参考的实际加载相量 |
| IN / MID / OUT 单 CW 峰值 | 0.474341649025 / 0.316227766017 / 0.158113883008 V | `√2×|V_RMS|`，不推广到积分噪声 |

负载/源可用功率之比为 0.25；负载/DUT 输入交付功率之比为 1/3。
两者分别保存，不能共用一个无参考面说明的“增益”标签。
RFModel 电流正方向是**进入器件端口**，R1/R2 输出端电流为 −I。
例如 R2 输出端的加载 V/I 为 −50 Ω；它不是 ZPORT、ZIN、ZOUT 或 DCR。

## 导出身份门与冻结比较门限

**先锁定变量身份，再比较数值**：保存原始变量全名、所属分析/数据集、形状/下标、节点或端口、
路径顺序与方向、谱类型、频率/信道范围、单位、峰值/RMS、相位参考和来源设置。
不能由“数值接近 oracle”倒推出它是哪种量。导出应保留原始复数实/虚部及足够往返 binary64 的精度；
仅截图、截断显示文本、无单位或无方向的数据记为不可比较。dB 转换只在功率/电压及参考单位明确后进行。

| 变量与验收身份 | 比较规则 |
|---|---|
| Linear F、ZPORT、四项复 S | 必须同时完整导出；与上述频率、参考阻抗和 S 解析值比较。 |
| RF DCP 的首节点 | 帮助明确使用内部源参考，目标 1 mW；不与 0.75 mW 比较。 |
| RF DCP 的 OUT | 仅在导出证实为本 CW、正向期望信号和完整信道积分后，比较负载 0.25 mW。 |
| RF DCV 的 OUT | 仅在确认峰值、dBV/线性 V 单位和同一正向 CW 后，比较 0.15811388300841897 V 峰值。 |
| CP、CV、MID 的谱及功率、其他端口 V/P | 保留诊断；全方向叠加与定向传输谱身份尚未完全落实，不自动当成净功率或总相量验收。 |
| ZIN/ZOUT、SZIN/SZOUT、DCR、CNV/CNP | 保留定义及导出；本候选不设厂商数值兼容判定。 |

标量用 `|actual−expected| ≤ atol + rtol×|expected|`；复 S 用复差的模。
以下为**采集前实验判定政策**，不是 Keysight 精度保证，也不修改历史容差：

| 量 | atol | rtol |
|---|---:|---:|
| 频率 | 0.001 Hz | 0 |
| 参考阻抗（复数） | 1e−8 Ω | 1e−10 |
| 无量纲复 S | 1e−10 | 1e−8 |
| 已通过身份门的线性功率 | 1e−10 W | 1e−7 |
| 已通过身份门的峰值电压 | 1e−9 V | 1e−7 |

该无谐振被动电阻网络条件温和；门限给跨实现计算与单位转换留余量，又能明确拒绝源参考面混淆、
RMS/峰值混淆、反射符号错误和端口次序错误。若实际导出精度不足，应重新采集；
不得在看到偏差后放宽门限。任何方案或判定修改另建有理由的版本并重新采集。
身份不清、变量缺失、未运行和数值失败分别记录；不将未比较项计为通过。

## 当前 C++ 对应与剩余边界

复用[行为系统 SDK](../examples/behavioral-system-sdk/README.md) 的同一模型/连线数据：
`StaticSParameterModel → ModelAdapter → analyze_linear` 得完整外部 S；
`conversion_device(100e6,{1},omit_intrinsic_noise) → analyze_conversion_simulation` 得各器件端口 RMS V/I、a/b 和净功率。
源波为 `√0.001`，源/负载反射均为零，参考阻抗均为 50 Ω；这是明确噪声省略策略。
`analyze_linear_path` 可分别提供源可用、输入接受、负载交付功率，但不自动等价于厂商路径 GAIN/CGAIN。
现有示例扫描 1/2 GHz；本候选固定 100 MHz，需要后续独立采集/重放输入，不能声称示例已经执行了本实验。
