# 失配二端口功率增益

`include/rfmodel/power_gain.hpp` 提供三种独立的测量函数，返回无量纲线性功率比。它们接受共同正实数参考阻抗下的二端口 S 矩阵；源、负载反射系数必须使用相同参考。换算 dB 可对正增益取 `10*log10(gain)`，零增益对应负无穷。

| API | 定义 | 终端约束 |
|---|---|---|
| transducer_power_gain(S, source, load) | 负载吸收功率 / 源可用功率 | abs(source)<1，abs(load)<=1 |
| operating_power_gain(S, load) | 负载吸收功率 / 输入端净接受功率 | abs(load)<=1，输入净接受功率必须为正 |
| available_power_gain(S, source) | 输出可用功率 / 源可用功率 | abs(source)<1，输出共轭匹配必须为被动负载 |

源、负载参数默认零（参考匹配）。源可用功率分母无定义、零/负净接受功率以及非被动的输出共轭匹配均明确抛出 domain_error。非法矩阵、非有限输入或不满足终端约束抛出 invalid_argument，无法表示的中间量和增益抛出 overflow_error。不会把负功率比取绝对值后伪装成有效增益，也不将某一种增益无法定义自动等同于所有增益均不可计算。

## 公式与求解约定

令 gs、gl 为源和负载反射系数，ds=1-S11*gs，dl=1-S22*gl，D=ds*dl-S12*S21*gs*gl。

- 换能功率增益：abs(S21)^2*(1-abs(gs)^2)*(1-abs(gl)^2)/abs(D)^2。
- 工作功率增益：abs(S21)^2*(1-abs(gl)^2)/(abs(dl)^2-abs(S11*dl+S12*S21*gl)^2)。
- 可用功率增益：abs(S21)^2*(1-abs(gs)^2)/(abs(ds)^2-abs(S22*ds+S12*S21*gs)^2)。

这些表达式直接由 b=S*a、a1=e+gs*b1、a2=gl*b2 和净功率差推导。实现直接使用行列式和消去分母后的表达式，避免先计算反射系数引入本不存在的可去奇点。极接近奇异或净功率相消的情形仍受双精度限制，本接口不提供条件数或稳定性认证。

SystemVue 2023 本机帮助 `sim/Gain_and_Impedance.html` 明确将模型 Gain 定义为 S21，而路径测量采用工作功率增益。因此不能用 abs(S21)^2 代替所有路径增益。当前接口是构建路径分析所需的基础测量，尚未实现完整多级路径选择、首级源失配修正及 SystemVue 路径结果导入。

## 验证证据

`tests/power_gain_test.cpp` 将复数双向网络在九组源/负载组合下的增益与 LinearNetwork 实际求解后的端口功率对照；验证输出共轭匹配下的可用增益、开短路反射负载的零吸收功率，以及主动端口和奇异边界。简单失配例子 S11=1/3、S22=1/2、S21=2、S12=0，在参考匹配终端下三种增益分别为 4、4.5、16/3，避免把不同定义混为一谈。
