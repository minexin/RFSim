# 前向频谱链路分析

`analyze_spectrum(input, source_reference_ohms, stages)` 按顺序执行 SpectrumStage，并返回输入总功率及每级名称、参考电阻、完整输出频谱和总功率。阶段描述包括输入/输出参考电阻及求值回调；执行前检查相邻参考一致性，禁止隐式改参考值。回调负责真实的参考转换，元数据本身不转换波量。

当前是前向、级间匹配的链路执行器。各级共享整数频率网格，可以产生或移除频率项，但不得修改 spacing_hz。全谱总功率按各音的模平方相加（含 DC），不等同于仅基波功率。任一级失败时抛出带阶段名称的错误，不返回部分结果；回调外部副作用无法回滚，应使用纯求值回调。

`transmit_linear_spectrum` 按输入各音频率构建 LinearNetwork，提取所选两个外端口的 S21 并作用于该音。外部源/负载匹配，线性子网络内部仍保留反射求解。DC 输出必须实数；显著虚部被拒绝，浮点舍入量级的虚部可归零。零透射项从输出频谱移除，不自动外推器件频率数据。

端到端回归以 100/103 MHz 双音经过三阶放大器、90 MHz LO 混频器和理想 IF 低通。输出保留 10/13 MHz 基波及 7/16 MHz IM3，幅度和总功率按解析值检查。测试还检查参考不匹配时不调用任何阶段、非法改频率网格的阶段定位和复数 DC 拒绝。

尚不包含级间失配的非线性闭环、谐波平衡、反馈路径、随机噪声频率转换、SystemVue RF System Analysis 的完整路径预算语义或模型文件工作流。各线性/噪声/非线性原语的局部可用不代表完整系统兼容。
