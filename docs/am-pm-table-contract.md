# AM-PM 表格语义：待决策说明

状态更新（2026-10-12）：A01 有界辨识已完成 24 次分析（2 次基线、1 次恢复基线、21 个诊断点），见 [实测结论及反例](systemvue-am-pm-datapoints-a01.md)。非零点支持自然三次样条候选、保留数值圈数和源相位相加；名义 0 dBm 相位归零及近零 DCP 报表偏差仍未解释。完整 DataPoints 契约尚未闭合，不宣称厂商兼容，不新增表格内核实现。下文为此次实测前的候选讨论，其中“尚无采集”描述属于历史状态。

## 已确认

本地官方帮助与样例的哈希和核验耗时见 [来源记录](../validation/systemvue-2023-am-pm-table-contract.json)。

- Legacy DataPoints：等长的输出功率 dBm 与基波输出电压相位 deg 数组；功率单调递增。
- Compression Curve：输入功率横轴、绝对相位；缺省 PM 为零；相位在低端和高端之外分别保持首值、末值。
- 官方样例从已有数据集输出节点 2 的 DCP/DCPH 构造 DataPoints，未规定点间算法。
- Legacy 页面三阶公式属于 PointDerivative；另一个 Compression Curve 页面描述快速扫描步长，都不能用作 DataPoints 插值依据。

## 三项待决策契约

| 问题 | 现有来源不足之处 | 推荐自定义方案 |
|---|---|---|
| 插值 | 未规定使用 dBm/W/幅度横轴的何种插值 | dBm 分段线性，明确命名为 RFModel 自定义 |
| 跨 ±180° | 未规定展开或最短相位路径 | 保留输入数值，不自动展开；170→-170 的中点为 0° |
| 折点导数 | 未规定不光滑点的处理 | 返回左右导数及不可微状态，不伪造普通 Jacobian |

候选 A（推荐）：PiecewiseLinearDbmPhaseCurve，常值外推，先只提供标量曲线与导数信息。开区间 q=2P*dθ/dP=(20/ln(10))*dθ/dP_dBm；折点左右斜率不同时无普通导数。该契约不等于 SystemVue 兼容。

候选 B：自定义平滑曲线，先审定插值族及端点导数。候选 C：暂不实现，等待明确资料或区分性参考。

还须保留输入/输出功率、绝对/增量相位的区别；不能直接把 Compression Curve 接到已有输出功率增量旋转适配器。跨语言接口另行安排。

## 后续验收

选择契约后覆盖节点、区间中点、零功率、常值外推、跨圈相位、左右有限差分、非法/重复节点和数值溢出。厂商辨识可用 [0,10,20] dBm → [0,20,0] deg，比较 5/15 dBm、端外点及折点两侧，再单独检查相位跨圈与非零小信号相位。当前只记录候选数学值，没有执行参考采集，也没有提升兼容状态。
