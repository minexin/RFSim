# SystemVue 2023 RFAMP 单位增益诊断

## 结论与边界

第二级 G=0 dB 的已知级联差异，在本轮受控案例中可由等效线性功率增益
`1.00000023` 解释，约合 `9.98877195e-7 dB`。SystemVue 参数回读仍为 1。
这是对 SystemVue 2023.0.0.11903 输出行为的实验结论，尚未核实内部实现，
不能声称已经找到其源代码中的修正逻辑。

核心 C++/C/Python 放大器继续使用调用者给出的增益，不自动施加这个偏移。
原始 0 dB 兼容性报告仍不通过。新报告明确标为 diagnostic_only，
eligible_for_compatibility=false；假设验证通过与名义兼容性通过分别记录。

## 实验设计

使用既有 Source → RFAmp1 → RFAmp2 → Port_2 专用副本。第一放大器增益
10 dB，第二放大器做增益扫描；其他设置固定为 OP1dB=20、OPSAT=23、
OIP2=40、OIP3=30 dBm，ZIN/ZOUT/Zref=50 Ω，RISO=140 dB，关闭噪声和
次级谱再混频，分析最大阶数 3、通道宽度 1 MHz。源带宽为 1 Hz。

共 17 次无警告的新采集：

- 12 点增益扫描：−1、−0.001、−1e-6、−1e-8、0、+1e-8、+1e-6、
  +0.001、1、5、10、20 dB。单音 −20 dBm / 90°。
- 4 个独立检查：单音 −30 dBm / 0°、单音 −10 dBm / 45°、双音各
  −30 dBm / 0°和90°、双音各 −10 dBm / 0°和90°，第二级均为 0 dB。
- 1 个显式等效增益检查：单音 −20 dBm / 90°，第二级设置为
  9.98877194e-7 dB。

扫描中的 11 个非零增益点按原始参数全部通过；0 dB 及四个独立 0 dB
案例均不通过。最小非零偏移为 ±1e-8 dB，更小的邻域没有测试，
不能由本轮结果推断任意接近零的点或其他版本的行为。

## 推导与独立验证

在失真限幅阈值以下、保持输出截点不变时，第 n 阶生成波的幅度与线性
功率增益的 n/2 次方成正比。因此，取 0 dB 与 +1e-8 dB 的相同新生成
谱项，按以下关系估计等效增益：

`G_effective = G_near × |wave_zero / wave_near|^(2/n)`

只使用 −20 dBm 单音的 H2 估计参数。H3 和三阶同频互调分别算出同一
数值，误差在浮点舍入量级。使用该参数重放时保持 OP1dB/OPSAT/OIP2/OIP3
不变，按新的增益换算输入参考截点，避免把输出截点一起改动。

四个独立功率/双音案例不参与拟合，均支持同一参数变换。显式设置等效
增益的 SystemVue 采集与原始 0 dB 采集的对应 RF 波相对差异最大约
1.7e-15，也独立支持这一解释。

| 检查方式 | 案例通过 | 数值检查失败 | 最大复幅度相对误差 |
| --- | --- | --- | --- |
| 调用者名义增益 | 12/17 | 125/383 | 3.0013e-7 |
| 仅诊断层采用推导增益 | 17/17 | 0/383 | 4.49994e-8 |

两种重放均使用原有 1e-7 复幅度和功率阈值，没有改变容差。
383 项检查包含按来源的波/功率、来源合并输出和各级 RFPwrIn。
它们不代表完整 NodeTotal、路径预算或次级再混频验收。

## 工程与重放

参考采集工具现允许有限范围 −10 到 20 dB 的小数增益，拒绝非有限值和
越界值。采集器使用不依赖系统区域设置的数值字符串，归档严格核对命令、
参数回读、数据时间戳、拓扑、分析设置、警告及 SHA256。

```powershell
python scripts/reference/diagnose-cascade-unity-gain.py build-msvc/Release/rfmodel_c.dll validation/systemvue-2023-cascade-gain-captures.json build-reference/unity-gain-replay.json
```

该诊断命令退出 0 表示“等效增益假设与完整实验组一致”，不代表名义兼容。
报告同时保留 nominal_passed=false。六个回归测试覆盖真实实验、缺失/重复
案例、受控参数、相位损坏、独立等效增益证据，以及诊断不会修改原始 Library。

本轮不加入未经更广泛验证的隐式增益补丁。后续需要检查单级 RFAMP、其他

完整高阶及次级失真生成仍是长期目标中的未完成项。

单音 −30 dBm、相位 0°、第二级 10 dB、RISO=100 dB 的既有基线。
