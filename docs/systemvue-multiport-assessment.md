# SystemVue 2023 多端口模型评估

2026-09-29 直接读取本机 `Help/systemvue.qch` 中的模型帮助页，核对参数与公开行为说明。
源页面及 SHA-256 已在 `validation/systemvue-2023-rf-models.json` 的模型清单中保存。
本次是文档语义评估，没有运行新的 SystemVue 仿真，数值兼容仍未验收。

## 两路功分器

核对页：`rfdesign/SPLIT2.html`、`rfdesign/SPLIT290.html`、`rfdesign/SPLIT2180.html`。
三者共享 IL、ISO、PH2、GBal2、PH3、Zref、Zin、Zout、Ta 参数。

| 参数 | 帮助页定义 | RFModel 映射与差异 |
|---|---|---|
| IL | 每路总插入损耗，默认 3.02 dB | 不等于 EqualPowerDividerModel 的额外损耗；理想等分时额外损耗为 IL−10log10(2) |
| GBal2 | 只加到输入至厂商端口 3 的增益，默认 0 dB | 第二支路幅度为 10^((-IL+GBal2)/20) |
| PH2、PH3 | 各输出相对于输入的相位，单位度 | 使用各支路复数传输系数；厂商 1/2/3 对应 RFModel 0/1/2 |
| ISO | 默认 30 dB 的有限输出隔离 | 当前 IsolatedPowerDividerModel 是完全隔离，不能表示默认值 |
| Zref、Zin、Zout | 分别指定参考及输入/输出阻抗 | 当前原语只覆盖匹配且共用实参考阻抗的情况 |
| Ta | 可覆盖分析温度，单位摄氏度 | 当前显式调用被动噪声 API，输入开尔文；没有自动继承分析温度 |

PH2/PH3 的默认值分别是：SPLIT2 为 −90°/−90°，SPLIT290 为 0°/−90°，
SPLIT2180 为 −90°/−270°。名称中的“0 度”表示输出间相位差，不能解释为各路零相位。
在完全隔离、端口匹配的限制下，映射到新 API 的两项传输系数为：

```text
v[0] = polar(10^(-IL/20), PH2*pi/180)
v[1] = polar(10^((-IL+GBal2)/20), PH3*pi/180)
```

帮助页提示不合理的损耗、隔离和增益组合可能表现为有源并给出警告；RFModel 的新原语
直接拒绝总支路功率大于 1 的输入。这是明确的行为差异。帮助页未给出全部隔离路径的
复相位关系，本轮没有猜测其数值，也没有把上述受限映射称为完整 SPLIT 模型。

## 90 度混合耦合器

核对页：`rfdesign/HYBRID1.html`。公开参数包含 IL、CPL、ISO、GBAL、PBAL、Zref、
四个端口阻抗及 Ta。默认 IL 约 0.5 dB、CPL 约 3.0103 dB、ISO 40 dB。
文档以直通 −90°、耦合 0° 描述相位；现有 QuadratureCouplerModel 则为直通 0°、
耦合 +90°，相对相位相同但绝对相位不同。外部存在反射或多路径合成时，不能忽略该差异。

帮助页对两条输出路径给出的幅度 dB 表达式均含 −IL−CPL，GBAL 以相反符号各分配一半；
PBAL 仅作用于 −90° 路径。现有原语以功率比例 q 与 1−q 定义耦合/直通，
不能在任意 CPL 下直接当作厂商公式。完整模型还需要核对符号端口编号、隔离路径、
不平衡后的无源性及 DC 行为；帮助明确各路径 DC 阻断规则并不相同。

## 下一步验收

使用专用工作区分别采集三个 SPLIT 模型和 HYBRID1 的完整复数 S 矩阵，至少包含
默认参数、理想隔离极限、改变输出相位、增益不平衡、非默认耦合和零频点。
保留参数回读及新鲜度证据，逐元素比较后再确定有限隔离实现及适配器。
当前目录条目仍保持未验收；不能用解析测试或相对相位一致性替代 SystemVue 对照。
