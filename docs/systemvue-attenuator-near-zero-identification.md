## 归一化关系得到解释

对八个点的两个噪声端点，原始谱满足：

    P_spectrum = |V|² * Re(1/Z) / 2
    CND_path   = |V_total|² / (2 * 50)
    CND_path / P_total = 1 / [50 * Re(1/Z_total)]

当 Z 为实数时，最后一式就是 Z/50。这里 50 Ω 来自已有参考条件，不是拟合参数；空的默认阻抗属性仍没有被称为完整运行时默认解析。

此前常规条件下约 −5e−9 的比例，只是 Z≈49.99999975 Ω 时的结果。旧 1e−8 dB 点的谱阻抗约 49.9999951571 Ω，因而比例变化到约 0.9999999031424643。本轮两个新点分别为 0.9999999948850018 和 0.9999999952487997。固定 −5e−9 因子不能覆盖这些情况。

使用上一阶段的有效系数 k*=1.3806504e−23，还可从实测信号与自身噪声重构：

    CND_in  = k* * 290 * DCP_in / P_available
    CND_out = k* * 290 * DCP_out / P_available
              + exported_device_noise_voltage² / (2 * 50)

P_available=1e−19 W。逐分量 V/Z/P、噪声求和、路径换算和上述预算在所有选定端点的最大相对残差为 6.44e−16。这是利用实测分量进行的**事后重构**，不是独立预测，也不证明厂商内部直接执行这些表达式。

旧 1e−8 dB 档案中没有导出的器件自身噪声谱项；报告保留“未导出”，不宣称物理自身噪声为零。其它点存在该项。理想 k*T*(1−g) 仍无法逐位解释近零自身噪声：新 3e−6/6e−6 dB 的该分量相对偏差约 +3.28066e−4/−2.19214e−4；因分量本身很小，对总噪声的影响也很小。产生这些内部谱量的数值机制继续开放。
