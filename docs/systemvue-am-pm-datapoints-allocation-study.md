# DataPoints 增益与源功率分配实验

[顺序复现](systemvue-am-pm-datapoints-order-study.md)在固定表格和 20 dB 增益下，重复观察到名义输出 0、−0.000001 dBm 的零相位增量，而 +0.000001、±0.00001 dBm 有约 33.4375° 增量。本轮改变增益与源功率的分配，检查两个明确预登记的有限模式扩展；完整 DataPoints 兼容仍未验收。

## 预登记设计

[计划](../validation/am-pm-datapoints-allocation-plan-20261014.json)固定表格 `[-5,5,15] dBm / [10,40,-20]°`、100 MHz、普通源相位 37° 及原压缩设置。令 ε = `1e-6 dBm`，q 为名义输出目标、G 为增益，源表达式精确为 `q-G dBm`。

|固定顺序|G / dB|q / dBm|角色|
|---|---:|---|---|
|0–2|20|0、−ε、+ε|历史复现|
|3–6|18|0、−ε、+ε、−2|四个新预测配置|
|7–10|22|0、+ε、−ε、+2|四个新预测配置|
|11|20|0|末尾历史零点复现|

共十二次分析，无预留或替代调用。十二个输入目录独立制备，各有十七处精确 XML 修改并进行反向语义审核；仅首尾 G20 零点配置的文件字节相同。每次打开前工作区数必须为零，仍使用已识别的同一 SystemVue 进程，不声称重置了内部缓存。

两个新候选都使用冻结自然三次样条与实测普通原始输出功率。输出离散模式在 q 精确为 0 或 −ε 时令增量为零；输入离散模式在名义源功率精确为 −20 或 −20.000001 dBm 时令增量为零。两者在各自集合之外均预测原始功率样条。这个“其余情况使用样条”的扩展是新增假设，旧数据没有证明它。

主预测分母为八个新配置，其中六个配置的两个候选预测不同，两个 +ε 配置均预测非零。另行评估有限指纹：输出零/非零指纹只适用于六个等 q 配置，输入零指纹只适用于两个等名义输入配置，不能把各自适用分母写成八。四个旧候选继续局部计分，但前轮十点全组失败不撤销。

## 采集门控与原始输入

每次分析前后核验十八项 SI 参数、精确 G/Pwr 表达式、明确完成状态和空诊断；保留普通输入与输出的原始频谱。新增归一化器保留输入 `F1/P1/V1/Z1/ID1/IDNo/IDName` 七个原始节点及元数据，识别源的两个目标频谱分量，校验其频率为中心频率 ±0.5 Hz、功率与电压/阻抗关系、两分量功率一致及输入相位。历史频谱摘录只用于离线校验，不是本轮新增测量。

同增益普通 DCP 输入相对于该组零点的比值须满足 `10^(q/10)`，相对容差 `1e-10`；相对于首个 G20 零点的跨增益比值须满足 `10^((q-G+20)/10)`，相对容差 `1e-7`，允许微小负载差异。源参数、原始频谱输入与 DCP 输入是不同量。原始输入比值、原始增益及原始/DCP 差异仅描述，不作为跨增益精确相等的门控。

首尾两个 G20 零点各自进行完整历史基线比较，功率相对容差 `1e-7`、相位绝对容差 `1e-5°`。各次 Quick Sweep 仍为输入 −30 至 0 dBm、步长 0.5 dB：G20/G18/G22 首次扫描分别建立该增益控制，九次后续扫描仅与同增益控制比较，输入相对容差 `1e-10`、输出 `1e-7`、相位 `1e-5°`。G18/G22 首次扫描是新的辅助参考。全部 732 个登记扫描观测及至多十二个额外终点均排除在普通预测分母之外。

采集无效、输入身份、历史零点基线或同增益扫描门控失败才停止后续调用；候选、指纹、跨增益比较与历史 ε 复现差异均保留为科学结果。失败调用消耗额度，保留全部尝试，不改容差、不加点、不拟合。缺失调用及未完成对照必须逐项报告。

执行前冻结计划、制备、归一化、评分器及[完整执行工作流](../validation/am-pm-datapoints-allocation-workflow-20261014.json)。恢复原工作区时不追加分析，核验 245 个路径、247 个有序参数项和元数据；未知或未完成的应用状态保留现场。

## 解释边界与当前状态

六对等名义输出及两对等名义输入比较，分别保留 DCP 输入/输出、原始输入/输出的解析 binary64 精确相等标志与残差。近似相等的原始功率与不同相位不能否定任意极窄分支的未知输出函数，也不能确定精确阈值。

固定增益块仍与时间、顺序和隐藏状态混杂；本轮不能独立区分源表达式机制与物理输入机制，也不能排除任意增益相关分支。两个候选都可能失败或通过；有限成功不授权产品径向导数或完整兼容结论。此前 G7/G−3 零输出证据使用不同表格，只限制跨表格的全局说法，不能冒充本轮同配置对照。

[采集前离线验证](../validation/am-pm-datapoints-allocation-preregistration-validation-20261014.json)记录制备、原始输入归一化和评分三组测试，在 Windows 与实际 Ubuntu WSL 各通过 **12/12、24/24、21/21**；四个辅助脚本的 PowerShell 语法和内嵌 C# 编译通过。检查期间没有调用 COM。该记录不代表完整 C++ 构建、CTest 或远程 CI。
