# 混频与多项式的多来源系统图

现在可在同一个 `rfmodel.coherent-system` version=1 模型中组合
`polynomial_amplifier`、`ideal_mixer_bank` 和 `linear_network`。
链路可包含多级多项式、频率转换、并行支路及合路。数值运算调用既有 C++/C ABI；
Python 图层负责按流保存来源、路由及显式阶数筛选。

[示例](../examples/coherent-mixed-polynomial.json)以 800 MHz / 1.2 GHz 两个
同源复波输入，由 1 GHz LO 混频；两路差频在 200 MHz 相干叠加，再进入
`v_out=v_in+0.5*v_in²`。参考阻抗 50 Ω，LO 相位 0.3 rad。

```powershell
$env:PYTHONPATH = "$PWD/python"
python -m rfmodel examples/coherent-mixed-polynomial.json --library build-msvc/Release/rfmodel_c.dll --output build-reference/mixed-polynomial-result.json
```

## 相干身份和来源贡献

物理相干类别与原始来源历史分开管理。混频器仍按 RF/LO 相干组对分组：
同一类别的不同 RF 输入折叠到同一 IF 时，先合并复波再计算功率。
每条流独立保存该分量的来源表达式；即使两条流拥有同一相干组，它们也可以
有不同来源项及幅度，不能用一个全局“组号到来源”的表覆盖彼此。

线性网络和多项式求值时，将各非零来源贡献分别送入原生运算，再按物理
身份归并。内部临时组号只用于展开和路由，最终功率由恢复后的真实相干
分量计算；绝不把临时贡献当成互不相干的功率相加。

多项式的交叉项及排列数来自既有原生多项式引擎；没有除以总输入波。
例如 IF 的两个贡献为 +0.01 和 −0.01，平方后的三条非零贡献仍保存，
它们的总和为零。原生多项式仍跳过单项零幅度及零系数；这不会删除其他
不同来源的非零相消贡献。表达式求和保留合并后的精确零项。

混频的 LO 是规定的无噪声 CW。差频 RF>LO 时使用 RF·conj(LO)，
RF<LO 时使用 conj(RF)·LO，和频使用 RF·LO。共轭同时翻转整个历史中
所有因子的符号和复幅度，故再次混频也保留前级 RF/LO 的来源。

转换后的物理分量成为后续多项式的相干基元。相对于同一物理基元的正号
幂归为 harmonic，其余新生成项为 intermod；一次传递保留原类型。
原始 RF/LO 历史单独保存在来源项内，不由 harmonic 标签替代。

## 可审计输出与阶数政策

混合图的结果新增：

- `origin_representation="complex-expression"`；
- `source_order_policy="rf-and-lo-factors"`；
- `origin_roots` 中的 `role` 区分 `rf` 和 `lo`；LO 的支撑带宽为零；
- 每流 `origins` 对应每个物理分量，内部 `terms` 保存各项的
  `source_factors`、`source_order`、`rf_order` 和实际复 `amplitude`；
- 多项式阶段同时报告物理输入数、展开贡献数、生成与舍弃路径数。

`max_source_order` 明确计数所有 RF 和 LO 根因子的出现次数，保留重复和
共轭因子。`rf_order` 单独报告 RF 因子次数。一次混频后的 RF 一次项
来源阶数为 2；其平方为 4。此规则是 RFModel 的显式来源截断政策，
**尚未证明等同于 SystemVue MaxOrder**。它也不是本地多项式次数限制。

筛选在原生展开之后、同一物理分量合并之前按每条来源路径执行。
生成/舍弃计数指展开的非零局部路径，不等同于最终分量数。
所有保留项验证频率与带宽和根历史一致，来源复波之和就是分量复波。

没有混频器的既有多项式图仍使用原先单来源结果结构；没有多项式的既有
混频/压缩图保留既有执行路径。混合图的来源表示由上述字段显式区分。

## 资源边界

沿用原生多项式的最高九阶、最多 64 个活跃输入、4096 条 RF 输出、
10000000 次枚举访问上限。这里“活跃输入”指展开后的非零来源贡献，
因此物理分量较少而来源很多时也可能超限；不靠静默裁剪继续运算。

线性网络最多 4096 条展开入射贡献，贡献与观察端口的工作量仍按既有限制检查，
每个网络阶段仅提取一次各频点的等效 S。混频每批最多 2048 个物理 RF 分量。
全图最多保存 65536 个分量、65536 条来源项及 1048576 个来源因子，
并保留原有流数、阶段数及表达式运算边界。出错时 CLI 不覆盖既有结果文件。

## 证据与未完成项

新增回归以独立稀疏频谱混频/多项式卷积对照复波，覆盖多项式—混频—
多项式链路、再次混频全历史共轭、IF 相消、跨流不同来源、线性复权合路、
独立源功率相加、既有镜像抑制、分数带宽、资源上限及 CLI 失败原子性。

本轮没有新增 SystemVue 实测或修改已有参考阈值。高阶 RFAMP 系数、
SystemVue 全局阶数/子谱合并、LO 驱动及变频噪声仍未完成。
混合图暂不接入 `limited_amplifier`、`cascaded_amplifier` 或
`fundamental_compression`：它们需要先按真实相干总波确定共同压缩驱动，
再将同一响应施加到各来源，不能用临时展开贡献的独立功率代替。
该组合明确报错，旧压缩图不受影响。这是下一步需要解除的实现边界。
